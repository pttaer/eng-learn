## 1. Why NPR Trains Band 8.0+ Listening & Speaking
NPR shows feature educated native speech across economics, behavioral psychology, and cultural critique. Non-native speakers learn how native intellectuals frame arguments, qualify assertions, and tell stories.

## 2. High-Frequency Spoken Discourse Signposts

| Discourse Marker | Rhetorical Function |
| :--- | :--- |
| *"As it turns out..."* | Revealing unexpected reality or scientific finding |
| *"What struck me was..."* | Highlighting key insight or anomaly |
| *"Here's the thing..."* | Directing listener attention to the crux of the problem |
| *"At the end of the day..."* | Synthesizing ultimate conclusion or bottom line |
